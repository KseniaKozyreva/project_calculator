### 🧮 Web Project Cost Calculator

Веб-приложение для автоматизированного расчета стоимости разработки IT-проектов. Сервис позволяет клиентам и менеджерам быстро оценить бюджет на создание сайта на основе выбранных параметров, объема работы и срочности.

### 💻 Функционал приложения (Суть проекта)

Приложение представляет собой интерактивную форму со следующими возможностями: 

* **Выбор типа проекта:** Лендинг, Интернет-магазин, Веб-портал (каждый тип имеет свою базовую стоимость).
* **Учет трудозатрат:** Ввод планируемого количества часов работы команды.
* **Коэффициент срочности:** Возможность выбрать "Срочный заказ", который автоматически добавляет наценку к итоговой стоимости.
* **Динамический вывод:** Расчет итоговой суммы происходит на стороне сервера и выводится пользователю на экран.

### 📐 Алгоритм расчета (Бизнес-логика)

Итоговая стоимость формируется по формуле: Итого = (Базовая цена типа проекта + (Часы * 1000 руб.)) * Коэффициент срочности 

* **Базовые тарифы:** 

  * Лендинг — 5 000 руб.
  * Интернет-магазин — 15 000 руб.
  * Веб-портал — 30 000 руб.
* **Почасовая ставка:** 1 000 руб./час.
* **Срочность:** Наценка +50% (коэффициент 1.5), если активен чекбокс "Срочный заказ".

### 🛠 Технологический стек

* **Backend:** Python 3.x, Flask (микрофреймворк для обработки запросов и бизнес-логики)
* **Frontend:** HTML5, CSS3, Jinja2 (шаблонизатор Flask)
* **Архитектура:** Монолитное веб-приложение с разделением логики расчетов и отображения.
